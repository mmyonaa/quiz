## 0. 조사 방법과 근거의 등급

문서 안의 주장은 근거 등급을 표시했다. 섞이면 판단이 흐려진다.

| 등급 | 뜻 |
| --- | --- |
| **[실측]** | 로컬 dev(4322)를 브라우저로 직접 열어 데스크톱 1440×900 · 모바일 390×844에서 확인 |

## 1. 지금 UI 진단 [실측]

### 잘 되어 있는 것 (건드리지 말 것)

1. **담백한 단일 컬럼과 절제된 색.** 코랄 액센트 하나로 상태를 말하고 나머지는 뉴트럴이다. 문제 풀이에 시선이 남는다.
2. **시험별 액센트 전환.** 정처기 코랄 / 정보보안기사 블루로 "지금 어느 시험인지"를 색이 말한다. 라이트·다크 각각 대비를 맞춰 둔 것도 드물게 성실한 부분이다.
3. **풀이 화면의 정보 밀도.** 상단 한 줄에 `1/10` · 타이머 · 북마크 · 난이도 · 영역이 다 있고 그 아래 진행바가 붙는다. 군더더기가 없다.
4. **키보드 우선.** `1`–`4` 선택, `←`/`→` 이동, `Enter` 다음. 안내를 화면 하단에 노출한 것까지 맞다.
5. **해설의 질과 배치.** 결과 화면에서 내 답 / 정답 / 해설이 한 카드에 붙어 있어 오답 복기가 한 흐름이다.

### 부족한 것

| # | 관찰 [실측] | 왜 문제인가 |
| --- | --- | --- |

| D6 | 개념 노트에 **읽음/숙련도 표시가 없다.** 좌측 트리는 문항 수만 센다. | 46~90개 주제를 순회하는 사용자가 자기 위치를 못 잡는다. |
| D7 | 모바일에서 홈 필터가 **7줄**을 먹어 `시작하기`가 접힌 아래에 있다. 풀이 화면의 `다음`도 우하단 인라인이다. | 엄지 영역(하단 고정)에 주 액션이 없다. 모바일 학습 앱의 기본기다. |

## 2. 벤치마크

### 2.1 같은 시장 — 국내 CBT 기출 사이트

기능 커버리지의 **기준선**이다. 미감은 참고할 게 거의 없지만(대부분 광고 밀도가 높고 2010년대 레이아웃), 수험생이 당연하게 여기는 기능은 여기에 다 있다.

**CBT문제은행 — cbtbank.kr** [확인]
- 풀이 시작 전 **옵션 4종**을 준다: ① 정답 확인 방식(클릭 시 바로 정답 확인 / 채점 방식) ② 문제 출력 순서(순서대로 / 무작위) ③ 보기 출력 순서(순서대로 / 랜덤) ④ 해설 표시(감추기 / 모두 펼쳐 보기).
- **가져올 것**: ①이 D3의 답이다. 홈 폼에 "채점 방식: 바로 확인 / 제출 후" 토글 하나. ④는 결과 화면에 "해설 모두 접기"로.
- **가져오지 말 것**: ②③은 이 사이트에 무의미하다 — 회차 기출이 아니라 매번 무작위 출제라 이미 순서가 섞인다.

**뉴비티 — newbt.kr** [확인]
- 상단 내비가 `[문제] [시험] [북마크] [포럼]`. **북마크가 1급 메뉴**다. 테마 전환도 헤더에 있다. 나만의 연습문제 등록을 지원한다.
- **가져올 것**: 북마크(저장한 문제·개념)를 헤더에서 한 번에 닿게. 지금은 `/my` 안에 묻혀 있다.
- **가져오지 말 것**: 포럼·사용자 문항 등록. 정적 사이트의 성격과 운영 비용이 안 맞는다.

**전자문제집 CBT — comcbt.com / 시나공 CBT** [통설]
- 실제 CBT 시험 화면(문항 번호판·답안 표기·남은 시간)을 그대로 재현하는 것이 이 계열의 핵심 가치다.
- **이미 갖춘 것**: 모의고사의 OMR 답안 표기란·건너뛰기·번호 클릭 이동. 여기는 이미 경쟁력이 있다 — 홈 카피에서 더 세게 말해도 된다.

> 정리: **국내 경쟁 사이트 대비 이 사이트가 이긴 지점은 개념 노트와 실기 필답, 진 지점은 학습 기록과 풀이 옵션이다.**

### 2.2 학습 루프 — 글로벌

**Duolingo** [통설]
- 한 화면 한 과업. 하단에 **고정 액션 바**가 있고, 답을 내면 그 바가 그대로 초록/빨강 피드백 패널로 부풀며 정답·해설·`계속` 버튼을 담는다. 세션이 끝나면 정확도·시간·연속 기록을 요약 화면으로 준다.
- **가져올 것**: (a) 모바일 풀이 화면의 하단 고정 액션 바 → D7. (b) 즉시 채점 모드일 때 같은 자리에서 피드백을 펼치는 구조 → D3. (c) 세션 종료 요약 → D4.
- **가져오지 말 것**: 하트/생명, 캐릭터 일러스트, 리더보드, 축하 애니메이션. 성인 수험생용 도구의 톤을 깬다. 스트릭은 §2.3의 절제된 형태로만.

**Quizlet — Learn 모드** [통설]
- 같은 카드 뭉치를 **모드**(학습 / 테스트 / 매치)로 갈라 입구를 명확히 한다. 틀린 항목을 세션 안에서 더 자주 되돌린다(진짜 SRS는 아니다).
- **가져올 것**: 홈을 "조건 폼"이 아니라 **모드 카드 3장**(빠른 연습 / 모의고사 / 오답 복습)으로 열기 → D1·D2. 조건 선택은 모드를 고른 뒤로 미룬다.

**Anki** [통설]
- 카드마다 다음 복습일을 갖는 진짜 간격 반복, 그리고 **잔디 형태의 복습 히트맵**과 "오늘 밀린 카드 수".
- **가져올 것**: 오답노트에 **가벼운 재출제 간격**(예: 오답 → 1일 → 3일 → 7일, `localStorage`에 다음 노출일만 기록). 홈에 "오늘 복습할 오답 N개".
- **가져오지 말 것**: 스케줄러 파라미터 노출, 데크/서브데크 개념. UI 복잡도가 Anki의 가장 큰 약점이다.

**Brilliant** [통설]
- 개념 설명 사이사이에 문제를 끼워 넣어 읽기와 풀기가 한 흐름이다.
- **이미 갖춘 것**: 개념 노트의 '확인 문제'(정답 가림 + 펼치기). **덜 갖춘 것**: 여기서 틀린 것이 오답노트로 들어가지 않는다. 이으면 사이트 전체가 한 루프가 된다.

**Khan Academy** [통설]
- 주제마다 숙련도 단계(친숙함 → 능숙 → 마스터)를 색으로 표시하고, 코스 전체 진행도를 한 바로 보여 준다.
- **가져올 것**: 개념 노트 좌측 트리의 문항 수 옆에 **주제별 숙련도 점**(내 정답률 기반 3단계) → D6. 데이터는 이미 오답노트·풀이 이력에 있다.

### 2.3 결과 리포트

**Microsoft 인증 스코어 리포트 / AP 성적 대시보드 패턴** [통설]
- 공통 골격: **문항 수준 + 카테고리 수준 2단 분석**, 약한 카테고리에 **행동 항목**을 붙임(색으로 약함→강함 표시).
- **가져올 것** → D4·D5. 결과 화면 최상단을 이렇게 바꾼다:
  - 점수 큰 숫자 + 합격선/과락선을 그은 가로 막대
  - **과목(또는 영역)별 정답률 막대 5~6줄** — 40점 미만은 과락 색으로
  - 가장 약한 영역 2개에 대해 `이 영역만 10문제 더 풀기` / `개념 노트에서 이 주제 읽기` 버튼
  - 그 아래에 지금의 전 문항 해설 목록(기본 접힘, "틀린 문제만 보기"는 유지)

### 2.4 미감·상호작용

**Linear · Vercel(Geist)** [통설]
- 좁은 색 팔레트, 촘촘한 타이포 스케일, 키보드 우선(`⌘K`), 절제된 모션(120~180ms). 지금 이 사이트가 이미 같은 계열이다 — 방향은 맞다.
- **가져올 것**: `⌘K` 팔레트 하나로 "주제 검색 → 개념 노트 이동 / 영역별 연습 시작"을 잇기. 개념 노트에 이미 주제 검색이 있으니 전역으로 올리는 정도다.

**Monkeytype** [통설]
- 미니멀 그 자체인데 **끝나고 나오는 통계 밀도는 높다**(그래프 + 지표 6종). "평소엔 비우고, 결과에서 몰아 보여 준다"는 이 사이트에 그대로 맞는 태도다.
- 지금 결과 화면에 이미 `풀이 시간 17초 · 문항당 평균 2초`가 있다. 여기를 지표 블록으로 키우면 된다.

**Stripe Docs · MDN** [통설]
- 3열(좌 내비 / 본문 / 우 페이지 내 목차)과 읽기 위치 표시.
- **가져올 것**: 개념 노트 영역 상세에 **우측 in-page 목차**(주제 앵커 목록 + 현재 위치 하이라이트). 좌측은 영역·주제 트리, 우측은 지금 문서 안 위치 — 역할이 겹치지 않는다. 1100px 이상에서만.

| 1 | 결과 화면 상단에 **영역별 정답률 막대 + 약점 CTA** | D4·D5 | §2.3 | 상 | 중 | `src/pages/[...exam]/index.astro` 결과 렌더 |

## 4. 명시적으로 하지 않을 것

가져오기 쉬워 보이지만 이 사이트의 성격과 어긋나는 것들. 나중에 "왜 안 했지"를 다시 논의하지 않기 위해 적어 둔다.

- **게이미피케이션 장치**(하트·XP·리더보드·캐릭터·축하 애니메이션) — 성인 수험생 도구의 톤을 깬다. 스트릭도 넣는다면 헤더 구석의 숫자 하나까지.
- **커뮤니티**(포럼·댓글·사용자 문항 등록) — 정적 사이트 + 운영 1인이라는 전제와 안 맞는다.
- **회차별 기출 재현** — 자체 제작 문항이라는 원칙과 충돌한다.
- **서버 저장이 필요한 통계** — 지금 유저 데이터는 Supabase(북마크·오답)뿐이다. 학습 기록은 우선 `localStorage`로, 로그인 사용자만 나중에 승격한다.
